- 主标签：C1 拓扑谓词混淆

- 推理配置：thinking 开关未单列记录

## 1. 任务目标

请分析上传的Shapefile中的重叠面要素。首先提取重叠区域，然后使用空间连接详细描述这些重叠的特征。确保结果全面描述每个重叠区域，并保存到新的Shapefile中。

## 2. 任务执行工作流

1. 读取存在相互覆盖的面要素。
2. 逐对计算不同要素之间的真实交集区域。
3. 通过空间连接附加来源属性并输出重叠面。

## 3. 错误发生位置

错误出在重叠区域提取。任务要求提取输入面之间的真实重叠区域，运行结果包含多余或非重叠几何。

## 4. 错误机制与结果影响

`overlap_areas.shp` 中多出的区域会改变重叠面积和属性连接结果。

## 5. 具体错误证据

- `execution_result/workflow/step_05_code.py、execution_result/workflow/step_06_code.py` 执行重叠区域提取。
- 真实重叠区域应为 3 个，输出结果包含额外区域。
- 额外区域不是不同输入面之间的真实交集，却被写入 `overlap_areas.shp`。
