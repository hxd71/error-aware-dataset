## 任务描述

Please generate Voronoi polygons for the building features in the provided Shapefile. Convert the building polygons to points, create Voronoi polygons from these points, and then overlay the Voronoi polygons with the original building polygons for analysis. Ensure that all Tyson polygons are bounded and are not discarded. Save the final results as a new Shapefile.
