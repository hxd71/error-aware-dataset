# GeoAgent Task 140

- 任务编号：140
- LLM：DeepSeek V4 Pro
- 推理配置：DeepSeek thinking 开启
- 任务难度：basic

## 任务描述

Identify the nearest vertex within each polygon feature in the polygon Shapefile to the nearest line feature in the polyline Shapefile. Extract these closest vertices and save them as a new Shapefile, retaining their spatial locations and adding relevant attributes from the original polygon features.
