# GIS 错误证据：GeoAgent Task 56

- 主标签：B3 缺失数据误判
- LLM：qwen3.6-plus（dashscope）
- 推理配置：thinking 开关未单列记录
- 视觉审查：至少审查一项可视化成果

## 1. 任务目标

将数据保存为Shapefile格式。用户的目标区域是像素值为0的区域。

## 2. 任务执行工作流

1. 读取高程栅格并区分值 0 与 NoData。
2. 仅对有效的值 0 像元建立二值掩膜。
3. 将目标像元矢量化为 Shapefile。

## 3. 错误发生位置

错误出在目标像元识别阶段。任务要求提取有效像元值为 0 的区域，但源栅格没有有效的 0 值目标像元。

## 4. 错误机制与结果影响

错误运行把 NoData 或掩膜外区域当作值 0 区域，生成了不存在的目标面；`zero_pixel_area.shp` 不应有目标要素。

## 5. 具体错误证据

- `zero_pixel_area.shp` 包含 1 个要素。
- 源栅格没有有效的值 0 目标像元。
- 该要素来自 NoData/掩膜区域与有效值 0 的区分失败。
